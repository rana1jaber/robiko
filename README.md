# روبيكو 🤖

لعبة عربية مجانية لتعلّم JavaScript من الصفر. تكتبين كودًا حقيقيًا، وينفّذه الروبوت روبيكو ويتنقل بين 9 كواكب و29 مهمة.

## الملفات

| الملف | محتواه |
|---|---|
| `index.html` | هيكل الصفحة: الخريطة، المحرر، اللوحة، ومحرك تشغيل كود اللاعب |
| `style.css` | كل التصميم والحركات |
| `levels.js` | الكواكب والمهمات: الشرح، الأمثلة، الخرائط، التلميحات والحلول |
| `script.js` | منطق اللعبة: تشغيل الكود، الخريطة والكواكب، روبيكو المعلّم، الأصوات، حفظ التقدم |

## التشغيل

افتحي `index.html` في المتصفح. لا يحتاج إلى تثبيت أي شيء.

## صوت روبيكو

نصوص التسجيل وأسماء الملفات في `audio/recording-script.md`، ونسخة مكتوبة للنطق الآلي في `audio/tts-script.csv`. وأي جملة ليس لها ملف MP3 يقرؤها صوت المتصفح.

## النشر على GitHub Pages

ارفعي كل الملفات ومجلد `audio` إلى repository، ثم اختاري الفرع `main` من Settings ← Pages.

## إضافة مهمة جديدة

افتحي `levels.js` وأضيفي object جديدًا داخل `missions` في الكوكب الذي تريدينه، ويحتوي على: `title` و `lesson` و `sample` و `task` و `map` و `starter` و `hint` و `solution`.

في الخريطة `map`: `#` جدار، `.` أرض، `R` الروبوت، `G` العلم، `*` جوهرة.
