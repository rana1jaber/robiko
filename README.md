# روبيكو 🤖

لعبة عربية مجانية لتعلّم JavaScript من الصفر. تكتبين كود حقيقي، والروبوت روبيكو ينفّذه ويتنقل بين 9 كواكب و29 مهمة.

## الملفات

| الملف | وش فيه |
|---|---|
| `index.html` | هيكل الصفحة: الخريطة، المحرر، اللوحة، ومحرك تشغيل كود اللاعب |
| `style.css` | كل التصميم والحركات |
| `levels.js` | الكواكب والمهمات: الشرح، الأمثلة، الخرائط، التلميحات والحلول |
| `script.js` | منطق اللعبة: تشغيل الكود، الخريطة والكواكب، روبيكو المعلّم، الأصوات، حفظ التقدم |

## التشغيل

افتحي `index.html` في المتصفح. ما يحتاج تثبيت أي شي.

## النشر على GitHub Pages

ارفعي الملفات الأربعة في repository، وبعدها من Settings ← Pages اختاري الفرع `main`.

## إضافة مهمة جديدة

افتحي `levels.js` وأضيفي object جديد داخل `missions` في الكوكب اللي تبينه، فيه: `title` و `lesson` و `sample` و `task` و `map` و `starter` و `hint` و `solution`.

في الخريطة `map`: `#` جدار، `.` أرض، `R` الروبوت، `G` العلم، `*` جوهرة.
